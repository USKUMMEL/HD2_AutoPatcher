# HD2 AutoPatcher

HD2 AutoPatcher updates Helldivers 2 mod patches after game updates.

It supports Unit, Particle, and Wwise audio patch data.

## How to use

1. Download and open `HD2PatchFixer.exe` from the latest release.
2. Select your Helldivers 2 `data` folder.
3. Choose either a single patch or a compressed mod ZIP.
4. Choose an output location and click **Run Patcher**.

## Weapon and armor ID swaps

- **Weapon ID swaps:** detected automatically when the weapon Unit has a verified rig and animation reference match.
- **Armor/helmet ID swaps:** enter the original armor or helmet source archive in **ID SWAP SOURCE ARCHIVE(S)**. Leave it empty for normal, non-ID-swap armor/helmet mods.

## Supports Single Patch and Compressed Mod Patches

Allows multiple mod patches inside one ZIP file to be patched at the same time, for example a compressed mod package with a manifest.
